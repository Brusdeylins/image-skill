# Image Prompt Guidelines

Generic best practices for high-quality photographic image prompts. English
prompts work best.

## Prompt Formula

**[Subject] + [Scene / setting] + [Lighting] + [Camera + Lens] + [Quality]**

- **Subject**: the main focus, described concretely (who/what, pose, wardrobe,
  colours). Name an accent colour explicitly when it matters
  (e.g. "a crimson red `#A01441` blazer" -- the hex values throughout this
  file are illustrative placeholders; substitute the user's own brand
  colours).
- **Scene / setting**: where it happens and any background detail.
- **Lighting**: "soft diffused light", "golden hour backlighting",
  "studio three-point lighting".
- **Camera + Lens**: "shot on Canon EOS R5 85mm f/1.4", "Hasselblad 120mm" —
  drives depth of field and realism.
- **Quality**: "8k", "sharp focus", "shallow depth of field",
  "professional colour grading".
- **Style**: "commercial photography", "editorial photography",
  "corporate lifestyle".

## Optional Elements

- **Text in image**: when the scene allows it (screens, whiteboards, banners),
  add the literal text: `text on screen reads "AI Strategy 2026"`.
- **Hex colours**: pass exact hex codes for brand accents
  (e.g. `#A01441`, `#139EAD`, `#F5B510`).

## Examples

**Portrait (2:3):**
```
Professional business woman in a crimson red (#A01441) blazer standing confidently
in a modern glass office lobby, holding a tablet showing "Digital Transformation",
shot on Canon EOS R5 85mm f/1.4, soft diffused natural light from floor-to-ceiling
windows, shallow depth of field, professional colour grading, 8k, commercial photography
```

**Wide background (16:9):**
```
Aerial view of a modern smart city at dusk with crimson red (#A01441) accent lighting
on key buildings, data visualization overlays floating above the skyline,
text on digital billboard reads "Innovation Hub", shot on Hasselblad 50mm f/2.8,
golden hour backlighting, cinematic colour grading, 8k, editorial photography
```

**Close-up (1:1):**
```
Close-up of hands typing on a laptop keyboard with a crimson red (#A01441) notebook
beside it, screen showing analytics dashboard, soft studio lighting,
shot on Canon EOS R5 85mm f/1.4, shallow depth of field, clean sharp focus,
8k, corporate lifestyle photography
```
