# Image Prompt Guidelines

## Corporate Style (msg systems Research)

Every image prompt should follow this formula:
**[Subject with CI accent] + [Scene] + [Lighting] + [Camera + Lens] + [Quality]**

Required elements:
- **CI accent color #A01441** as a visible element (red dress/blazer, red accent
  lighting, red design elements, red branding)
- **Camera reference**: "shot on Canon EOS R5 85mm f/1.4" or "Hasselblad 120mm"
- **Lighting**: "soft diffused light", "golden hour backlighting",
  "studio three-point lighting"
- **Quality**: "8k", "sharp focus", "shallow depth of field",
  "professional color grading"
- **Style**: "commercial photography", "editorial photography",
  "corporate lifestyle"

Optional elements:
- **Text in image**: When the scene allows (screens, whiteboards, banners),
  add text matching the slide content: 'text on screen reads "AI Strategy 2026"'
- **msg logo**: On podiums, banners, screens:
  'small red dot (#A01441) followed by lowercase "msg" text'
- **Secondary colors** for diagrams/graphics: #139EAD, #F5B510, #70DC51,
  #5866E3, #D74B97
